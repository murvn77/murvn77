## Sobre mí

Ingeniera de Sistemas con 4 años de evolución constante, desde el desarrollo de componentes específicos hasta la construcción de soluciones full-stack robustas (Angular, React, NestJS, Java Spring Boot). Con alta capacidad de adaptación, he integrado herramientas de orquestación y contenerización (Docker, Kubernetes) y control de versiones (Git/GitHub) en mi flujo de trabajo. Cuento además con experiencia adicional en el ecosistema ArcGIS (Esri).

Destaco por mi habilidad para trabajar en equipos multidisciplinarios y gestionar proyectos bajo marcos ágiles (Scrum). Tengo una mentalidad de aprendizaje continuo, orientada a la resolución de problemas complejos y al crecimiento profesional.
